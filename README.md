Matching algorithm for STEMM UCAS mentoring scheme 

Place the mentor and mentee files in the same folder as the script 

Generates 3 output files after the script is run
1. Main match file which contains the mentor email, followed by their assigned mentee emails next to it
2. Unmatched mentees due to overflow (Insufficient mentors from that course)
3. Mentors who have been assigned less mentee than their max number

Emails were exported so that they can be treated as unique identify for the individual 

Possible expansion by reading emails and drafting emails which can easily be copy pasted and sent 
- Expected 80 emails can be sent significantly faster
